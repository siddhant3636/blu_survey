# Blu Smart Charge Survey - Frontend

This is the React + Vite frontend dashboard for the Blu Smart Charge Survey application.

## Tech Stack
- **Framework**: React 18+
- **Build Tool**: Vite
- **Routing**: React Router DOM v6
- **Styling**: Modular Vanilla CSS with variables

## Getting Started

### Prerequisites
- Node.js (>=18.0.0)

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```

2. Configuration:
   Verify the API connection in `.env`:
   ```env
   VITE_API_URL=http://localhost:5000/api/v1
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it.
